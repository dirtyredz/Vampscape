# CLAUDE.md — working in Vampscape

A BepInEx 5 / HarmonyX mod for the Unity Mono game **Moonlight Peaks**: build-mode camera zoom
(hold Left Alt + scroll). This is a **standalone git repo** nested in the Moonlight Peaks workspace —
when working here, **this** repo is active: honor its own gate and baseline, not the workspace root's.
Default branch: **`master`**.

## Conventions

- **Commit identity:** `dirtyredz <dirtyredz@live.com>`. Never the work email.
- **Layout:** plugin `.cs` flat in `src/` (no `src/Vampscape/`); docs + `pack.ps1` at the repo root.
- **Versioning:** bump `<Version>` in [src/Vampscape.csproj](src/Vampscape.csproj) **only**, only
  when publishing. It's single-sourced into `[BepInPlugin]` via `GenerateModBuildInfo` in
  `Directory.Build.props` — never hardcode a version in `Plugin.cs`.
- **Synced canonicals:** `pack.ps1` and `Directory.Build.props` are generated by
  `../../tools/sync-mod-files.ps1` — edit them in the workspace, not here.
- **Never publish** `dist/`, `bin/`, `obj/`, `*.zip`, or decompiled game code (all gitignored).

## Build / test / release

```bash
dotnet build src/Vampscape.csproj
```
Deploys the DLL to the game's `BepInEx/plugins/MoonlightPeaksMods/Vampscape` automatically (pass
`-p:SkipDeploy=true` to skip). Pass `pack.ps1` for the release archive. **Don't launch the game**
from here — verification is the manual [TESTING.md](TESTING.md) checklist run by a human.

## Structure-review gate

This repo is gated (pre-push hook, installed 2026-08-22). Edit and debug freely — the review fires
once at **push** on the accumulated change, not per edit or per commit. Commit freely at logical
boundaries; Claude runs the review and pushes (asking first) when work is ready. `/gate status`
shows what's pending. `Last full review:` stamp lives in [STRUCTURE.md](STRUCTURE.md).
